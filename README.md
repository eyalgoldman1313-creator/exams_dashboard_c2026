# לוח מבחנים · סמסטר קיץ 2026/27

דשבורד סטטי (HTML/CSS/JS, בלי build) עם ספירה לאחור לכל מבחן.

- הספירה כוללת את היום ואינה כוללת את יום המבחן (מבחן מחר = 1 יום), לפי שעון ישראל, ומתעדכנת אוטומטית בחצות.
- לוחות נפרדים למועדי א׳ ולמועדי ב׳ — מעבר בלשוניות בראש העמוד או בהחלקה (במובייל). קישור ישיר: `#moed-a` / `#moed-b`.
- **זמן ללמוד (פומודורו)** בכל לוח: ריכוז 25 / הפסקה קצרה 5 / הפסקה ארוכה 15 (אחרי 4), שיוך כל פומודורו למבחן מתוך `EXAMS`, סטטיסטיקה יומית ולפי מבחן, וכפתור "התחל ללמוד" בכרטיסי המבחנים. ההגדרות, מצב הטיימר והסשנים נשמרים ב-localStorage (`pomodoro-settings`, `pomodoro-state`, `pomodoro-sessions`), והטיימר מחושב לפי `endTime`, כך שהוא מדויק גם אחרי רענון או כשהלשונית ברקע.
- לכל קורס צבע משלו, ציר זמן לכל מועד, ימי הפרש בין מבחנים, מצב בהיר/כהה.
- הנתונים נמצאים בראש `app.js` (`COURSES`, `EXAMS`) — לעדכון תאריך מספיק לערוך שם ולדחוף ל-GitHub; Vercel יפרוס מחדש אוטומטית.

הרצה מקומית: `python -m http.server 5173` ופתיחת http://localhost:5173
