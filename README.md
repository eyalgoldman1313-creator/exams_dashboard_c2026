# לוח מבחנים · סמסטר קיץ 2026/27

דשבורד סטטי (HTML/CSS/JS, בלי build) עם ספירה לאחור לכל מבחן.

- הספירה כוללת את היום ואינה כוללת את יום המבחן (מבחן מחר = 1 יום), לפי שעון ישראל, ומתעדכנת אוטומטית בחצות.
- לוחות נפרדים למועדי א׳ ולמועדי ב׳ — מעבר בלשוניות בראש העמוד או בהחלקה (במובייל). קישור ישיר: `#moed-a` / `#moed-b`.
- **זמן ללמוד** — דף טיימר נפרד (האייקון ליד כפתור מצב התצוגה, או `#timer`): ריכוז 25 / הפסקה קצרה 5 / הפסקה ארוכה 15 (אחרי 4 סבבים), רשימת משימות בסגנון Pomofocus עם הערכת סבבים וזמן סיום משוער, וסטטיסטיקה של היום ושל 7 הימים האחרונים. "התחל ללמוד" בכרטיס מבחן יוצר משימה לאותו מבחן ופותח את הטיימר. הכול נשמר ב-localStorage (`pomodoro-settings`, `pomodoro-state`, `pomodoro-sessions`, `pomodoro-tasks`), והטיימר מחושב לפי `endTime`, כך שהוא מדויק גם אחרי רענון או כשהלשונית ברקע. צליל הסיום (`sounds/timer-end.mp3`) מתנגן בלולאה עד לחיצה על "איפוס", ונעצר לבד אחרי 2 דקות (ניתן לשינוי בהגדרות).
- לכל קורס צבע משלו, ציר זמן לכל מועד, ימי הפרש בין מבחנים, מצב בהיר/כהה.
- הנתונים נמצאים בראש `app.js` (`COURSES`, `EXAMS`) — לעדכון תאריך מספיק לערוך שם ולדחוף ל-GitHub; Vercel יפרוס מחדש אוטומטית.

הרצה מקומית: `python -m http.server 5173` ופתיחת http://localhost:5173
